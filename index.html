Help & getting started

Install on Android

Host the app on HTTPS, open its address in Chrome, then use the browser menu and select Install app or Add to Home screen when offered.

Install on iPhone

Open the HTTPS website in Safari, tap Share, then choose Add to Home Screen if available.

Keep your media safe

Local browser storage can be cleared by the browser or device. Keep a separate copy of important original files.

This website is an informational landing page. It does not yet provide a public app-store listing or a live hosted download. Add verified store and download links before launch.

Frequently asked questions

Is VideoHub Pro a native Android APK?

The current starter is a Progressive Web App (PWA), not a native APK or AAB.

Can I download any video from social media?

No. Only download content you own or are authorised to download, using official platform mechanisms. Platform restrictions must be respected.

Will downloads always resume?

No. Resume depends on the source server supporting range requests and the browser retaining the required data.

Why is my download slow?

Speed depends on your internet connection, source server, file size, browser and network conditions. A fixed speed cannot be guaranteed.

Does the app work offline?

Some cached app-shell features may work offline after a successful HTTPS visit. Online content and external services still require connectivity.
