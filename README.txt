VideoHub Pro — Official website starter

Files:
- index.html: responsive one-page landing website with Features, About, Help, FAQ, Contact, Privacy draft and Terms draft sections.
- assets/icon-192.png and assets/icon-512.png: app icon assets copied from the PWA starter.

Publish:
1. Create a GitHub repository (for example, videohub-pro-website).
2. Upload index.html and the assets folder to the repository root.
3. In Settings > Pages, deploy from the main branch and root folder.
4. Open the HTTPS URL to test on mobile and desktop.

Before public launch:
- Replace the placeholder support contact with a monitored address.
- Add verified Play Store/App Store links only after the apps are actually published.
- Review the Privacy Policy and Terms against the real deployed app, hosting, analytics, ads and data practices; these are draft notices, not legal advice.
- Add a custom domain only after you own/control it.

The current PWA remains a web app, not a native APK/AAB. This landing website does not provide a live app download.
